## Chapter 16: 데이터 처리와 분석

우리는 매일 데이터에 둘러싸여 살고 있습니다. 성적표, 매출 보고서, 설문조사 결과, 서버 로그... 이 모든 것이 데이터입니다. 프로그래밍의 가장 실용적인 활용 중 하나가 바로 이런 데이터를 읽고, 정리하고, 분석하는 일입니다.

바이브 코딩에서는 AI에게 "이 CSV 파일을 읽어서 평균을 구해줘"라고 말하면 됩니다. 하지만 AI가 생성한 코드를 이해하고 결과를 검증하려면, 데이터 처리의 기본 개념을 알아야 합니다. 이 장에서는 Python의 표준 라이브러리만으로 다양한 데이터를 처리하고 분석하는 방법을 배웁니다.

---

### 학습 목표

이 장을 마치면 다음을 할 수 있습니다:

- CSV 파일을 읽고 기본 통계를 계산할 수 있다
- JSON 데이터를 파싱하고 중첩 구조를 탐색할 수 있다
- 서로 다른 형식 간 데이터를 변환하고 결측치를 정제할 수 있다
- 데이터를 그룹화하고 집계 통계를 산출할 수 있다
- 조건에 따라 데이터를 필터링하고 정렬할 수 있다
- 터미널에서 텍스트 기반 차트로 데이터를 시각화할 수 있다

### 16.1 CSV 데이터 처리

**CSV(Comma-Separated Values)**는 가장 널리 쓰이는 데이터 형식입니다. 엑셀에서 내보내기를 하면 CSV가 되고, 대부분의 데이터 분석 도구가 CSV를 지원합니다. 파이썬에서는 `csv` 모듈로 CSV 데이터를 쉽게 다룰 수 있습니다.

#### CSV 읽기의 기본 구조

CSV 처리의 핵심은 세 단계입니다:

1. **읽기**: `csv.DictReader`로 각 행을 딕셔너리로 변환
2. **가공**: 리스트 컴프리헨션으로 필요한 데이터 추출
3. **분석**: `statistics` 모듈로 통계 계산

> **Tip:** `csv.reader`는 각 행을 리스트로 반환하지만, `csv.DictReader`는 헤더를 키로 사용하는 딕셔너리로 반환합니다. 코드 가독성이 훨씬 좋아지므로 `DictReader`를 권장합니다.

---

**예제 16-01: CSV 읽기와 기본 통계**

학생 성적 데이터를 CSV로 정의하고, 평균, 중앙값, 최고점, 최저점 등 기본 통계를 계산합니다.

```python
# examples/python/chapter04/ex16_01_csv_basic_stats.py
import csv
import io
import statistics

csv_data = """이름,과목,점수
김민수,수학,85
이영희,수학,92
박철수,수학,78
정미래,수학,95
한지우,수학,88
오세훈,수학,73
최다은,수학,90
강준혁,수학,82
"""

# CSV 파싱
reader = csv.DictReader(io.StringIO(csv_data.strip()))
records = list(reader)

# 점수 목록 추출
scores = [int(row["점수"]) for row in records]

# 기본 통계 계산
print("=" * 40)
print("  수학 성적 기본 통계")
print("=" * 40)
print(f"  학생 수 : {len(scores)}명")
print(f"  평균    : {statistics.mean(scores):.1f}점")
print(f"  중앙값  : {statistics.median(scores):.1f}점")
print(f"  최고점  : {max(scores)}점")
print(f"  최저점  : {min(scores)}점")
print(f"  표준편차: {statistics.stdev(scores):.1f}")
print("=" * 40)
```

이 예제에서 핵심은 `csv.DictReader`와 리스트 컴프리헨션의 조합입니다. `[int(row["점수"]) for row in records]` 한 줄로 모든 점수를 숫자 리스트로 추출했습니다. `statistics` 모듈의 `mean`, `median`, `stdev` 함수를 사용하면 복잡한 수학 공식을 직접 구현할 필요가 없습니다.

> **Tip:** `io.StringIO`는 문자열을 파일처럼 다룰 수 있게 해줍니다. 실제 프로젝트에서는 `open('data.csv')` 등으로 파일을 읽지만, 예제에서는 외부 파일 없이 실행할 수 있도록 `StringIO`를 사용합니다.

### 16.2 JSON 데이터 처리

**JSON(JavaScript Object Notation)**은 웹 API에서 가장 많이 사용되는 데이터 형식입니다. 파이썬의 딕셔너리, 리스트와 구조가 거의 같아서 직관적으로 다룰 수 있습니다. `json` 모듈 하나면 충분합니다.

#### JSON 파싱 기본 흐름

| 함수 | 역할 | 예시 |
|------|------|------|
| `json.loads()` | JSON 문자열을 파이썬 객체로 변환 | `data = json.loads('{"a": 1}')` |
| `json.dumps()` | 파이썬 객체를 JSON 문자열로 변환 | `json.dumps(data, indent=2)` |
| `json.load()` | JSON 파일을 읽어서 변환 | `data = json.load(f)` |
| `json.dump()` | 파이썬 객체를 JSON 파일로 저장 | `json.dump(data, f)` |

> **Tip:** 한국어가 포함된 JSON을 출력할 때는 반드시 `ensure_ascii=False` 옵션을 추가하세요. 그렇지 않으면 한글이 `\uD55C\uAE00` 같은 유니코드 이스케이프로 표시됩니다.

**예제 16-04: JSON 파싱과 데이터 추출**

서점 도서 목록 JSON을 파싱하여 필요한 정보를 추출하고, 통계를 계산합니다.

```python
# examples/python/chapter04/ex16_04_json_parsing.py
import json

json_string = '''
{
    "서점": "바이브 북스",
    "위치": "서울 강남구",
    "도서목록": [
        {"제목": "파이썬 입문", "저자": "김개발", "가격": 28000, "재고": 45, "장르": "프로그래밍"},
        {"제목": "AI 시대의 코딩", "저자": "이미래", "가격": 32000, "재고": 30, "장르": "프로그래밍"},
        {"제목": "데이터 과학 기초", "저자": "박분석", "가격": 35000, "재고": 20, "장르": "데이터"},
        {"제목": "웹 개발 실전", "저자": "최풀스택", "가격": 30000, "재고": 38, "장르": "웹개발"}
    ]
}
'''

data = json.loads(json_string)

# 기본 정보 출력
print(f"  서점명 : {data['서점']}")
print(f"  위치   : {data['위치']}")

# 도서 목록과 통계 추출
books = data["도서목록"]
total_value = sum(b["가격"] * b["재고"] for b in books)
print(f"  총 재고 가치 : {total_value:,}원")

# 가장 비싼 도서 JSON 출력
most_expensive = max(books, key=lambda b: b["가격"])
print(json.dumps(most_expensive, ensure_ascii=False, indent=2))
```

**예제 16-05: 중첩 JSON 구조 탐색**

실무에서는 JSON이 여러 단계로 중첩되는 경우가 많습니다. 회사 조직도 데이터를 탐색하며 중첩 구조 처리 패턴을 익힙니다.

```python
# examples/python/chapter04/ex16_05_nested_json.py
import json

json_string = '''
{
    "회사명": "테크스타트",
    "부서": {
        "개발팀": {
            "팀장": "김개발",
            "인원수": 8,
            "프로젝트": [
                {"이름": "프론트엔드 개선", "상태": "진행중", "예산": 5000},
                {"이름": "API 리팩토링", "상태": "완료", "예산": 3000},
                {"이름": "모바일 앱", "상태": "계획중", "예산": 8000}
            ]
        },
        "디자인팀": { ... },
        "마케팅팀": { ... }
    }
}
'''

data = json.loads(json_string)
departments = data["부서"]

# 부서별 탐색: 딕셔너리의 .items()로 키-값 순회
total_budget = 0
for dept_name, dept_info in departments.items():
    print(f"[{dept_name}] 팀장: {dept_info['팀장']}, 인원: {dept_info['인원수']}명")
    for proj in dept_info["프로젝트"]:
        total_budget += proj["예산"]
        print(f"  - {proj['이름']} ({proj['상태']}) - {proj['예산']:,}만원")
```

중첩 JSON 처리의 핵심 패턴은 **바깥에서 안쪽으로 단계별 접근**입니다. `data["부서"]["개발팀"]["프로젝트"][0]["이름"]` 처럼 한 번에 깊이 접근할 수도 있지만, 반복문과 변수를 사용해 단계적으로 접근하는 것이 가독성과 유지보수 면에서 훨씬 좋습니다.

> **Tip:** 중첩 JSON을 다룰 때 `KeyError`가 자주 발생합니다. `dict.get("키", 기본값)` 메서드를 사용하면 키가 없을 때 에러 대신 기본값을 반환하므로 안전합니다. 예: `dept_info.get("팀장", "미정")`

### 16.3 데이터 변환과 정제

실무에서는 데이터가 항상 깔끔하게 정리된 상태로 오지 않습니다. 형식을 변환해야 할 때도 있고, 누락된 값이나 잘못된 데이터를 정리해야 할 때도 있습니다. 이 섹션에서는 이 두 가지 핵심 작업을 다룹니다.

#### CSV에서 JSON으로 변환

서로 다른 시스템은 서로 다른 데이터 형식을 사용합니다. CSV로 내보낸 데이터를 JSON 형식으로 변환해서 웹 API에 전달해야 하는 상황은 매우 흔합니다.

---

**예제 16-06: CSV에서 JSON으로 변환**

직원 데이터를 CSV에서 읽어 부서별로 그룹화된 JSON 구조로 변환합니다.

```python
# examples/python/chapter04/ex16_06_csv_to_json.py
import csv, io, json

csv_data = """직원ID,이름,부서,직급,연봉
E001,김민수,개발팀,선임,5200
E002,이영희,디자인팀,책임,5800
E003,박철수,개발팀,주임,4200
...
"""

reader = csv.DictReader(io.StringIO(csv_data.strip()))
records = list(reader)

# 숫자 필드 변환
for record in records:
    record["연봉"] = int(record["연봉"])

# 부서별 그룹화 JSON 생성
grouped = {}
for record in records:
    dept = record["부서"]
    if dept not in grouped:
        grouped[dept] = {"부서명": dept, "직원수": 0, "직원목록": []}
    grouped[dept]["직원수"] += 1
    grouped[dept]["직원목록"].append({
        "직원ID": record["직원ID"],
        "이름": record["이름"],
        "직급": record["직급"],
        "연봉": record["연봉"]
    })

result = json.dumps(grouped, ensure_ascii=False, indent=2)
print(result)
```

#### 데이터 정제: 결측치와 오류 처리

현실 세계의 데이터에는 빈 칸, 잘못된 형식, 범위를 벗어난 값 등이 포함되어 있습니다. 이런 "더러운" 데이터를 분석 가능한 상태로 만드는 것을 **데이터 정제(Data Cleaning)**라고 합니다.

**예제 16-07: 데이터 정제 (결측치 처리)**

나이가 비어 있거나, 점수가 100을 초과하거나, 이메일 형식이 잘못된 데이터를 감지하고 정제합니다.

```python
# examples/python/chapter04/ex16_07_data_cleaning.py
import csv, io, statistics

# 결측치와 오류가 포함된 CSV 데이터
csv_data = """이름,나이,점수,이메일,도시
```

### 16.4 기본 통계 분석

단순히 데이터를 읽는 것을 넘어, 의미 있는 인사이트를 뽑아내는 것이 분석의 목적입니다. 그룹별 집계와 종합 분석 리포트를 만들어 봅시다.

#### 그룹화와 집계

데이터 분석에서 가장 많이 하는 작업 중 하나가 **그룹별 집계(Group By Aggregation)**입니다. "카테고리별 매출은 얼마인가?", "지역별 주문 건수는?" 같은 질문에 답하는 것이죠.

---

**예제 16-08: 그룹별 집계 분석**

온라인 쇼핑몰 주문 데이터를 카테고리별, 지역별로 집계하고 교차 분석까지 수행합니다.

```python
# examples/python/chapter04/ex16_08_group_aggregation.py
import csv, io
from collections import defaultdict

csv_data = """주문ID,상품명,카테고리,수량,단가,지역
O001,노트북,전자기기,1,1200000,서울
O002,마우스,전자기기,2,35000,부산
O003,파이썬 입문서,도서,3,28000,서울
...
"""

# 매출액 계산
for r in records:
    r["매출액"] = int(r["수량"]) * int(r["단가"])

# 카테고리별 집계
cat_stats = defaultdict(lambda: {"주문수": 0, "총수량": 0, "총매출": 0})
for r in records:
    cat = r["카테고리"]
    cat_stats[cat]["주문수"] += 1
    cat_stats[cat]["총수량"] += int(r["수량"])
    cat_stats[cat]["총매출"] += r["매출액"]
```

```python
# 기본 패턴: [항목 for 항목 in 데이터 if 조건]
```

### 16.6 CLI 시각화 (텍스트 기반 차트)

데이터를 표로만 보면 전체적인 추세를 파악하기 어렵습니다. 그래프가 필요하죠. 하지만 CLI 환경에서는 matplotlib 같은 그래픽 라이브러리를 쓸 수 없습니다. 대신 **유니코드 블록 문자**를 활용한 텍스트 기반 차트를 만들 수 있습니다.

#### 텍스트 차트의 핵심 원리

텍스트 막대 그래프의 원리는 간단합니다:

1. 데이터의 **최댓값**을 기준으로 막대 최대 폭을 결정
2. 각 값을 최댓값 대비 **비율로 변환**
3. 비율에 따라 `"█"` 문자를 반복 출력

```python
max_val = max(values)
for label, value in data:
    bar_len = int(value / max_val * 40)  # 최대 40칸
    bar = "█" * bar_len
    print(f"{label} │{bar} {value}")
```

```python

def horizontal_bar_chart(title, data, max_width=40, value_suffix=""):
    """수평 막대 그래프를 출력합니다."""
    max_val = max(v for _, v in data)
    max_label_len = max(len(str(l)) for l, _ in data)

    print(f"\n  {title}")
    print(f"  {'=' * (max_label_len + max_width + 15)}")

    for label, value in data:
        bar_len = int(value / max_val * max_width) if max_val > 0 else 0
        bar = "█" * bar_len
        print(f"  {label:<{max_label_len}} │{bar} {value:,}{value_suffix}")

# 인기도 차트
languages = [
    ("Python", 85), ("JavaScript", 78), ("Java", 65),
    ("TypeScript", 58), ("C++", 42), ("Go", 35),
]
horizontal_bar_chart("프로그래밍 언어 인기도 (2024)", languages, value_suffix="점")

# 비율 차트 (퍼센트 막대)
categories = [("전자기기", 45.2), ("의류", 22.8), ("식품", 15.5)]
for label, pct in categories:
    filled = int(pct / 100 * 40)
    empty = 40 - filled
    bar = "█" * filled + "░" * empty
    print(f"  {label:<8} │{bar}│ {pct:.1f}%")
```

**예제 16-11: 설문 결과 분석기**

개발자 도구 사용 현황 설문조사 응답(JSON)을 분석하여 언어 분포, 만족도, AI 도구 사용률 등을 시각화합니다.

```python
# examples/python/chapter04/ex16_11_survey_analyzer.py
import json, statistics
from collections import Counter

survey_json = '''
{
    "설문제목": "개발자 도구 사용 현황 조사",
    "응답자수": 20,
    "응답": [
        {"이름": "응답자01", "연차": 1, "주언어": "Python", "만족도": 4, "AI도구사용": "예"},
        {"이름": "응답자02", "연차": 3, "주언어": "JavaScript", "만족도": 5, "AI도구사용": "예"},
        ...
    ]
}
'''

data = json.loads(survey_json)
responses = data["응답"]

# 1. 주 사용 언어 분포 (Counter 활용)
lang_counter = Counter(r["주언어"] for r in responses)
for lang, count in lang_counter.most_common():
    pct = count / len(responses) * 100
    bar = "█" * (count * 2)
    print(f"  {lang:<12} {bar} {count}명 ({pct:.0f}%)")

# 2. 만족도 분석 (별점 시각화)
satisfactions = [r["만족도"] for r in responses]
sat_counter = Counter(satisfactions)
for score in range(5, 0, -1):
    count = sat_counter.get(score, 0)
    stars = "★" * score + "☆" * (5 - score)
    print(f"  {stars} ({score}점) {'█' * (count * 2)} {count}명")

# 3. 연차별 AI 도구 사용률 비교
career_groups = {"주니어(1-3년)": [], "미들(4-6년)": [], "시니어(7년+)": []}
for r in responses:
    if r["연차"] <= 3: career_groups["주니어(1-3년)"].append(r)
    elif r["연차"] <= 6: career_groups["미들(4-6년)"].append(r)
    else: career_groups["시니어(7년+)"].append(r)
```

**예제 16-12: 로그 통계 대시보드**

서버 API 요청 로그를 분석하여 로그 레벨 분포, 엔드포인트별 통계, HTTP 상태 코드, 응답 시간 분석, 경고 알림까지 포함하는 운영 대시보드를 생성합니다.

```python
# examples/python/chapter04/ex16_12_log_dashboard.py
import json
from collections import Counter, defaultdict

# JSON Lines 형태의 서버 로그 데이터
log_data = """{"timestamp": "2024-10-01 09:15:23", "level": "INFO", "endpoint": "/api/users", "method": "GET", "status": 200, "response_ms": 45}
{"timestamp": "2024-10-01 09:15:45", "level": "INFO", "endpoint": "/api/products", "method": "GET", "status": 200, "response_ms": 82}
{"timestamp": "2024-10-01 09:16:02", "level": "WARNING", "endpoint": "/api/orders", "method": "POST", "status": 400, "response_ms": 120}
{"timestamp": "2024-10-01 09:17:15", "level": "ERROR", "endpoint": "/api/payment", "method": "POST", "status": 500, "response_ms": 3500}
...
"""

# 로그 파싱
logs = [json.loads(line) for line in log_data.strip().split("\n")]

# 로그 레벨 분포
level_counter = Counter(log["level"] for log in logs)
for level in ["INFO", "WARNING", "ERROR"]:
    count = level_counter.get(level, 0)
    pct = count / len(logs) * 100
    bar = "█" * int(pct / 100 * 30) + "░" * (30 - int(pct / 100 * 30))
    print(f"  {level:<8} {bar} {count:>2}건 ({pct:.0f}%)")

# 엔드포인트별 통계
endpoint_stats = defaultdict(lambda: {"count": 0, "total_ms": 0, "errors": 0})
for log in logs:
    ep = log["endpoint"]
    endpoint_stats[ep]["count"] += 1
    endpoint_stats[ep]["total_ms"] += log["response_ms"]
    if log["status"] >= 400:
        endpoint_stats[ep]["errors"] += 1

# 느린 요청 감지 (>1000ms)
slow_requests = [log for log in logs if log["response_ms"] > 1000]
```

### 정리

이 장에서는 파이썬 표준 라이브러리만으로 데이터를 처리하고 분석하는 다양한 기법을 배웠습니다.

#### 핵심 정리

| 주제 | 핵심 도구 | 활용 |
|------|-----------|------|
| CSV 처리 | `csv.DictReader` | 표 형식 데이터 읽기/쓰기 |
| JSON 처리 | `json.loads/dumps` | API 데이터, 설정 파일 |
| 통계 계산 | `statistics` 모듈 | 평균, 중앙값, 표준편차 |
| 빈도 분석 | `Counter` | 항목별 개수 집계 |
| 그룹 집계 | `defaultdict` | 카테고리별 합산/평균 |
| 필터링 | 리스트 컴프리헨션 | 조건부 데이터 추출 |
| 정렬 | `sorted()` + `key` | 단일/다중 기준 정렬 |
| 시각화 | 유니코드 블록 문자 | 텍스트 기반 막대 그래프 |

#### 바이브 코딩에서의 활용

데이터 분석은 바이브 코딩이 특히 빛을 발하는 영역입니다. AI에게 다음과 같이 요청해 보세요:

- "이 CSV 데이터의 평균, 중앙값, 표준편차를 구해줘"
- "이 JSON을 파싱해서 부서별로 그룹화해줘"
- "결측치가 있는 데이터를 정제하는 코드를 만들어줘"
- "월별 매출 추이를 텍스트 막대 그래프로 보여줘"
- "서버 로그를 분석하는 대시보드를 만들어줘"

AI가 생성한 코드의 패턴은 이 장에서 배운 것과 크게 다르지 않습니다. `csv.DictReader`, `json.loads`, `Counter`, `defaultdict`, 리스트 컴프리헨션 — 이 다섯 가지 도구를 이해하고 있으면, AI가 만든 데이터 처리 코드를 읽고 검증하고 수정하는 데 어려움이 없을 것입니다.

> **Tip:** 이 장의 모든 예제는 외부 라이브러리 없이 파이썬 표준 라이브러리만으로 동작합니다. 실무에서 대용량 데이터를 다룰 때는 `pandas` 라이브러리가 훨씬 효율적이지만, 기본 원리를 이해하면 pandas도 더 잘 활용할 수 있습니다.
