## 9.1 첫 번째 프로그램: 인사 프로그램

바이브 코딩의 시작은 언제나 **자연어 요청**입니다. 코드를 직접 작성하는 대신, 만들고 싶은 프로그램을 AI에게 말로 설명합니다.

첫 프로그램으로 간단한 인사 프로그램을 만들어 보겠습니다. AI에게 다음과 같이 요청합니다.

### 예제 9-1: "Hello, Vibe!" 프로그램 요청

**AI에게 보낸 요청:**

```
인사 프로그램을 만들어줘. 사용자 이름을 받아서 환영 메시지를 출력하는 프로그램이야.
```

**생성된 코드:**

```python
# examples/python/chapter02/ex9_1_hello_vibe.py
# 예제 9-1: "Hello, Vibe!" 프로그램

name = input("이름을 입력하세요: ")
print(f"환영합니다, {name}님! 바이브 코딩의 세계에 오신 것을 축하합니다!")
```

**실행:**

```bash
$ python examples/python/chapter02/ex9_1_hello_vibe.py
```

**결과:**

```
이름을 입력하세요: 민수
환영합니다, 민수님! 바이브 코딩의 세계에 오신 것을 축하합니다!
```

단 두 줄의 요청으로 동작하는 프로그램이 만들어졌습니다. `input()` 함수로 사용자 입력을 받고, `print()` 함수와 f-string으로 메시지를 출력합니다. 코드의 세부 문법을 몰라도, AI에게 원하는 것을 설명하는 것만으로 프로그램이 완성되었습니다.

> **Tip:** 첫 요청은 가능한 한 간단하게 시작하세요. "인사 프로그램을 만들어줘"처럼 핵심만 전달하면 AI가 기본적인 구조를 잡아줍니다. 세부 사항은 이후 대화에서 하나씩 추가하면 됩니다.

## 9.2 AI와 대화하며 개선하기

바이브 코딩의 핵심은 **한 번에 완벽한 코드를 만드는 것이 아닙니다.** AI와 대화하며 코드를 조금씩 개선해 나가는 과정입니다. 예제 9-1의 프로그램은 잘 동작하지만, 한 가지 문제가 있습니다. 사용자가 아무것도 입력하지 않으면 어떻게 될까요?

이름을 입력하지 않고 Enter를 누르면 "환영합니다, 님!"이라는 어색한 메시지가 출력됩니다. AI에게 이 부분을 개선해 달라고 요청합니다.

### 예제 9-2: 사용자 이름 입력받기 개선

**AI에게 보낸 요청:**

```
이름이 비어있으면 '익명'으로 처리해줘.
```

**생성된 코드:**

```python
# examples/python/chapter02/ex9_2_name_validation.py
# 예제 9-2: 사용자 이름 입력받기 개선 (빈 이름 처리)

name = input("이름을 입력하세요: ").strip()

if not name:
    name = "익명"

print(f"환영합니다, {name}님! 바이브 코딩의 세계에 오신 것을 축하합니다!")
```

**실행:**

```bash
$ python examples/python/chapter02/ex9_2_name_validation.py
```

**결과 (이름을 입력한 경우):**

```
이름을 입력하세요: 지은
환영합니다, 지은님! 바이브 코딩의 세계에 오신 것을 축하합니다!
```

**결과 (이름을 입력하지 않은 경우):**

```
이름을 입력하세요:
환영합니다, 익명님! 바이브 코딩의 세계에 오신 것을 축하합니다!
```

한 문장의 요청으로 코드에 **입력 검증(validation)** 로직이 추가되었습니다. `.strip()` 메서드로 공백을 제거하고, `if not name:` 조건으로 빈 문자열을 확인합니다. 이렇게 AI와 대화하다 보면 자연스럽게 프로그래밍 개념도 함께 익히게 됩니다.

> **Tip:** AI에게 수정을 요청할 때는 "이전 코드에서"라고 시작하지 않아도 됩니다. 같은 대화 안에서 AI는 앞서 만든 코드를 기억하고 있습니다. 간단하게 변경하고 싶은 부분만 말하면 됩니다.

## 9.3 코드 실행하고 결과 확인

바이브 코딩에서 코드를 실행하고 결과를 확인하는 과정은 매우 중요합니다. AI가 생성한 코드가 의도한 대로 동작하는지 직접 눈으로 확인해야 합니다. 이것이 바이브 코딩의 세 번째 단계인 **검증** 입니다.

프로그램을 계속 발전시켜 보겠습니다. 인사 메시지에 현재 시간도 함께 표시하면 더 친근한 느낌이 들 것입니다.

### 예제 9-3: 현재 시간 표시 추가

**AI에게 보낸 요청:**

```
현재 시간도 함께 보여줘.
```

**생성된 코드:**

```python
# examples/python/chapter02/ex9_3_with_time.py
# 예제 9-3: 현재 시간 표시 추가

from datetime import datetime

name = input("이름을 입력하세요: ").strip()

if not name:
    name = "익명"

now = datetime.now()
current_time = now.strftime("%Y년 %m월 %d일 %H시 %M분")

print(f"환영합니다, {name}님!")
print(f"현재 시간: {current_time}")
print(f"바이브 코딩의 세계에 오신 것을 축하합니다!")
```

**실행:**

```bash
$ python examples/python/chapter02/ex9_3_with_time.py
```

**결과:**

```
이름을 입력하세요: 민수
환영합니다, 민수님!
현재 시간: 2026년 01월 27일 14시 30분
바이브 코딩의 세계에 오신 것을 축하합니다!
```

"현재 시간도 함께 보여줘"라는 한 마디로 AI가 `datetime` 모듈을 가져오고, 시간을 한국어 형식으로 포맷팅하는 코드를 작성했습니다. `from datetime import datetime`이라는 import 구문이나 `strftime` 같은 메서드를 우리가 직접 찾아볼 필요가 없었습니다.

실행 결과를 확인했을 때, 시간이 올바르게 표시되는지, 이름 입력이 여전히 잘 동작하는지 확인합니다. 만약 예상과 다른 결과가 나온다면, AI에게 어떤 부분이 다른지 설명하고 수정을 요청하면 됩니다.

> **Tip:** 코드를 실행할 때마다 여러 가지 입력을 테스트해 보세요. 정상적인 입력뿐 아니라, 빈 입력, 특수 문자, 아주 긴 텍스트 등 다양한 경우를 시도하면 프로그램의 완성도를 높일 수 있습니다.

## 9.4 수정 요청하기

프로그램이 점점 발전하고 있습니다. 이번에는 인사 기록을 파일로 저장하는 기능을 추가해 보겠습니다. 나중에 누가 방문했는지 기록으로 남기고 싶은 것이죠.

### 예제 9-4: 인사말 파일로 저장하기

**AI에게 보낸 요청:**

```
인사 기록을 파일로 저장해줘.
```

**생성된 코드:**

```python
# examples/python/chapter02/ex9_4_save_to_file.py
# 예제 9-4: 인사말 파일로 저장하기

from datetime import datetime

name = input("이름을 입력하세요: ").strip()

if not name:
    name = "익명"

now = datetime.now()
current_time = now.strftime("%Y년 %m월 %d일 %H시 %M분")

greeting = f"[{current_time}] 환영합니다, {name}님! 바이브 코딩의 세계에 오신 것을 축하합니다!"

print(greeting)

with open("greeting_log.txt", "a", encoding="utf-8") as f:
    f.write(greeting + "\n")

print("인사 기록이 greeting_log.txt에 저장되었습니다.")
```

**실행:**

```bash
$ python examples/python/chapter02/ex9_4_save_to_file.py
```

**결과:**

```
이름을 입력하세요: 지은
[2026년 01월 27일 14시 35분] 환영합니다, 지은님! 바이브 코딩의 세계에 오신 것을 축하합니다!
인사 기록이 greeting_log.txt에 저장되었습니다.
```

**저장된 파일 확인:**

```bash
$ cat greeting_log.txt
```

```
[2026년 01월 27일 14시 35분] 환영합니다, 지은님! 바이브 코딩의 세계에 오신 것을 축하합니다!
```

AI는 `with open(..., "a")` 구문을 사용해 파일을 **추가 모드(append mode)** 로 열었습니다. 이렇게 하면 프로그램을 여러 번 실행해도 이전 기록이 지워지지 않고 계속 누적됩니다. `encoding="utf-8"`을 지정해서 한국어가 깨지지 않도록 한 점도 주목할 만합니다.

이처럼 바이브 코딩에서는 "파일로 저장해줘"라는 간단한 요청만으로도 파일 입출력, 인코딩 처리, 추가 모드 설정 등 여러 기술적 결정을 AI가 알아서 처리합니다.

## 9.5 기능 추가 요청하기

프로그램이 파일을 다루기 시작하면, 항상 **오류 처리**를 고려해야 합니다. 파일 저장이 실패할 수도 있기 때문입니다. 예를 들어, 디스크 공간이 부족하거나 파일 쓰기 권한이 없을 수 있습니다. AI에게 이런 상황에 대한 대비를 요청해 보겠습니다.

### 예제 9-5: 오류 처리 추가

**AI에게 보낸 요청:**

```
파일 저장 실패 시 오류 처리를 추가해줘.
```

**생성된 코드:**

```python
# examples/python/chapter02/ex9_5_error_handling.py
# 예제 9-5: 오류 처리 추가

from datetime import datetime

name = input("이름을 입력하세요: ").strip()

if not name:
    name = "익명"

now = datetime.now()
current_time = now.strftime("%Y년 %m월 %d일 %H시 %M분")

greeting = f"[{current_time}] 환영합니다, {name}님! 바이브 코딩의 세계에 오신 것을 축하합니다!"

print(greeting)

try:
    with open("greeting_log.txt", "a", encoding="utf-8") as f:
        f.write(greeting + "\n")
    print("인사 기록이 greeting_log.txt에 저장되었습니다.")
except PermissionError:
    print("오류: 파일에 쓸 권한이 없습니다.")
except OSError as e:
    print(f"오류: 파일 저장 중 문제가 발생했습니다 - {e}")
```

**실행:**

```bash
$ python examples/python/chapter02/ex9_5_error_handling.py
```

**결과 (정상 실행):**

```
이름을 입력하세요: 민수
[2026년 01월 27일 14시 40분] 환영합니다, 민수님! 바이브 코딩의 세계에 오신 것을 축하합니다!
인사 기록이 greeting_log.txt에 저장되었습니다.
```

**결과 (파일 권한 오류 시):**

```
이름을 입력하세요: 민수
[2026년 01월 27일 14시 40분] 환영합니다, 민수님! 바이브 코딩의 세계에 오신 것을 축하합니다!
오류: 파일에 쓸 권한이 없습니다.
```

AI가 `try-except` 구문을 사용해 오류 처리를 추가했습니다. `PermissionError`(권한 오류)와 `OSError`(일반 파일 시스템 오류)를 각각 다르게 처리해서, 사용자에게 무엇이 문제인지 알려줍니다. 프로그램이 오류 때문에 갑자기 멈추는 대신, 친절한 오류 메시지를 보여주게 되었습니다.

> **Tip:** 바이브 코딩에서 오류 처리를 요청하는 것은 좋은 습관입니다. AI는 발생할 수 있는 여러 가지 예외 상황을 알고 있으므로, "오류 처리를 추가해줘"라고만 요청해도 적절한 처리 코드를 생성해 줍니다.

## 9.6 완성된 프로그램

지금까지의 과정을 정리해 보겠습니다. 다섯 번의 대화를 통해 프로그램이 어떻게 발전했는지 확인합니다.

| 단계 | 요청 | 추가된 기능 |
|------|------|-------------|
| 예제 9-1 | 인사 프로그램을 만들어줘 | 기본 입력/출력 |
| 예제 9-2 | 이름이 비어있으면 '익명'으로 처리해줘 | 입력 검증 |
| 예제 9-3 | 현재 시간도 함께 보여줘 | datetime 활용 |
| 예제 9-4 | 인사 기록을 파일로 저장해줘 | 파일 입출력 |
| 예제 9-5 | 파일 저장 실패 시 오류 처리를 추가해줘 | 예외 처리 |

이제 마지막으로, 이 모든 기능을 깔끔하게 정리한 최종 버전을 AI에게 요청합니다.

### 예제 9-6: 완성된 프로그램 실행

**AI에게 보낸 요청:**

```
지금까지 만든 기능을 모두 합쳐서 함수로 깔끔하게 정리해줘. 시간대에 따라
아침/오후/저녁 인사말도 다르게 해줘.
```

**생성된 코드:**

```python
# examples/python/chapter02/ex9_6_complete.py
# 예제 9-6: 완성된 인사 프로그램

from datetime import datetime

def get_time_greeting():
    """현재 시간대에 맞는 인사말을 반환합니다."""
    hour = datetime.now().hour
    if hour < 12:
        return "좋은 아침이에요"
    elif hour < 18:
        return "좋은 오후예요"
    else:
        return "좋은 저녁이에요"

def get_user_name():
    """사용자 이름을 입력받습니다. 빈 입력이면 '익명'을 반환합니다."""
    name = input("이름을 입력하세요: ").strip()
    if not name:
        name = "익명"
    return name

def save_greeting(greeting, filename="greeting_log.txt"):
    """인사 기록을 파일에 저장합니다."""
    try:
        with open(filename, "a", encoding="utf-8") as f:
            f.write(greeting + "\n")
        print(f"인사 기록이 {filename}에 저장되었습니다.")
    except PermissionError:
        print("오류: 파일에 쓸 권한이 없습니다.")
    except OSError as e:
        print(f"오류: 파일 저장 중 문제가 발생했습니다 - {e}")

def main():
    """메인 함수: 인사 프로그램을 실행합니다."""
    name = get_user_name()
    time_greeting = get_time_greeting()
    now = datetime.now()
    current_time = now.strftime("%Y년 %m월 %d일 %H시 %M분")

    print(f"\n{'='*40}")
    print(f"  {time_greeting}, {name}님!")
    print(f"  현재 시간: {current_time}")
    print(f"  바이브 코딩의 세계에 오신 것을 축하합니다!")
    print(f"{'='*40}\n")

    greeting = f"[{current_time}] {time_greeting}, {name}님! 바이브 코딩의 세계에 오신 것을 축하합니다!"
    save_greeting(greeting)

if __name__ == "__main__":
    main()
```

**실행:**

```bash
$ python examples/python/chapter02/ex9_6_complete.py
```

**결과:**

```
이름을 입력하세요: 민수

========================================
```

## 정리

이번 챕터에서는 AI와 대화하며 프로그램을 만드는 바이브 코딩의 전체 과정을 직접 경험했습니다.

### 바이브 코딩의 핵심 흐름

```
요청 → 생성 → 실행 → 확인 → 개선 요청 → 반복
```

이 흐름을 따라 단 여섯 번의 대화로 다음과 같은 기능을 갖춘 프로그램을 완성했습니다:

1. **사용자 입력 처리** - 이름을 받아서 인사하기
2. **입력 검증** - 빈 이름을 '익명'으로 처리
3. **날짜/시간 표시** - 현재 시간을 한국어 형식으로 출력
4. **파일 저장** - 인사 기록을 파일에 누적 저장
5. **오류 처리** - 파일 저장 실패 시 대응
6. **코드 구조화** - 함수로 분리하여 정리

### 핵심 교훈

- **작게 시작하라**: 처음부터 모든 기능을 요청하지 말고, 가장 기본적인 것부터 시작합니다.
- **대화로 발전시켜라**: 한 번에 하나씩 기능을 추가하면 각 변화를 확실히 이해할 수 있습니다.
- **반드시 실행하라**: AI가 만든 코드는 항상 직접 실행해서 결과를 확인해야 합니다.
- **자유롭게 요청하라**: 문법이나 형식에 구애받지 않고, 자연스러운 한국어로 요청하면 됩니다.
