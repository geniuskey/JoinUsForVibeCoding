# Chapter 10: 프롬프트 엔지니어링 기초

바이브 코딩의 핵심은 AI에게 원하는 결과를 정확하게 전달하는 것입니다. 이 장에서는 AI 어시스턴트와 효과적으로 소통하기 위한 **프롬프트 엔지니어링**의 기초를 배웁니다. 같은 요청이라도 프롬프트를 어떻게 작성하느냐에 따라 결과의 품질이 완전히 달라집니다.

---

## 학습 목표

이 장을 마치면 다음을 할 수 있습니다:

- **프롬프트**의 개념과 중요성을 설명할 수 있다
- 좋은 프롬프트의 **5가지 특징**을 이해하고 적용할 수 있다
- **역할-맥락-요청-형식** 구조로 프롬프트를 설계할 수 있다
- **구체적인 요청**과 모호한 요청의 차이를 구분할 수 있다
- **Few-shot**(예시 제공) 기법으로 정확한 결과를 얻을 수 있다
- **Chain of Thought**(단계별 사고) 기법을 활용할 수 있다
- 자주 쓰는 프롬프트를 **템플릿**으로 만들어 재사용할 수 있다

## 10.1 프롬프트란 무엇인가?

**프롬프트(Prompt)**란 AI 어시스턴트에게 전달하는 지시 또는 요청 문장입니다. 바이브 코딩에서 여러분이 작성하는 모든 요청이 곧 프롬프트입니다.

일상생활에서 비유하면, 프롬프트는 식당에서 주문하는 것과 비슷합니다.

| 상황 | 모호한 주문 | 명확한 주문 |
|------|------------|------------|
| 식당 | "뭐 맛있는 거 주세요" | "매운맛 짬뽕 곱빼기에 면은 잘 익혀주세요" |
| AI | "코드 만들어줘" | "정수 리스트를 내림차순 버블 정렬하는 함수를 작성해줘" |

식당에서 구체적으로 주문할수록 원하는 음식을 받듯, AI에게도 구체적으로 요청할수록 원하는 코드를 받을 수 있습니다.

### 프롬프트가 중요한 이유

바이브 코딩에서 프롬프트는 곧 여러분의 **프로그래밍 언어**입니다. Python이나 JavaScript 같은 코드를 직접 작성하는 대신, 자연어(한국어)로 AI에게 지시를 내립니다. 이때 프롬프트의 품질이 생성되는 코드의 품질을 결정합니다.

```
프롬프트 품질 = 생성 코드 품질
```

같은 작업을 요청하더라도:
- **나쁜 프롬프트** --> 불완전하고 의도와 다른 코드
- **좋은 프롬프트** --> 완성도 높고 의도에 맞는 코드

이것이 바로 **프롬프트 엔지니어링**을 배워야 하는 이유입니다.

> **Tip:** 프롬프트 엔지니어링은 "AI를 잘 다루는 기술"이 아니라 "내가 원하는 것을 명확하게 표현하는 기술"입니다. 이 기술은 AI뿐 아니라 사람과의 소통에서도 큰 도움이 됩니다.

## 10.2 좋은 프롬프트의 5가지 특징

좋은 프롬프트에는 공통된 특징이 있습니다. 이 다섯 가지 특징을 기억하면 어떤 상황에서든 효과적인 프롬프트를 작성할 수 있습니다.

### 특징 1: 구체적이다

모호한 표현 대신 **무엇을**, **어떻게**, **어떤 형태로** 원하는지 명시합니다.

| 나쁜 프롬프트 | 좋은 프롬프트 |
|-------------|-------------|
| "정렬 해줘" | "정수 리스트를 내림차순으로 버블 정렬하는 함수를 작성해줘" |
| "파일 처리 해줘" | "텍스트 파일을 읽어 각 줄의 단어 수를 세는 함수를 작성해줘" |
| "API 만들어" | "사용자 관리 REST API의 엔드포인트 목록을 설계해줘" |

### 특징 2: 맥락을 포함한다

프로젝트 배경, 사용 환경, 대상 사용자 등 **맥락 정보**를 함께 제공합니다.

> "우리 프로젝트는 Python 3.11 기반 웹 크롤러입니다. 설정은 JSON 형식이고 URL 목록, 크롤링 간격, 출력 디렉토리를 포함합니다."

### 특징 3: 예시를 제공한다

원하는 입력과 출력의 **예시**를 보여주면 AI가 패턴을 정확히 파악합니다.

> "다음과 같이 변환해줘: 'hello world' --> 'Hello_World', 'ai assistant' --> 'Ai_Assistant'"

### 특징 4: 형식을 지정한다

결과의 **출력 형식**을 명시합니다 (JSON, 표, 리스트 등).

> "결과를 JSON 형식으로 반환해줘" 또는 "표(table) 형식으로 출력해줘"

### 특징 5: 제약조건을 명시한다

기술적 제한, 성능 요구사항, 금지 사항 등 **제약조건**을 알려줍니다.

> "외부 라이브러리 없이 표준 라이브러리만 사용해줘. 타임아웃은 3초로 설정해줘."

이 다섯 가지 특징을 실제 예제로 확인해봅시다.

## 10.3 프롬프트 구조: 역할-맥락-요청-형식

효과적인 프롬프트는 네 가지 요소로 구성됩니다. 이 구조를 **RCRF 구조**라고 기억하면 편리합니다.

```
[역할(Role)]     당신은 ~입니다.
[맥락(Context)]  ~한 상황에서, ~한 프로젝트에서
[요청(Request)]  ~를 해주세요.
[형식(Format)]   ~형식으로 반환해주세요.
```

### 1) 역할 (Role) - "당신은 누구입니다"

AI에게 전문가 역할을 부여하면, 해당 분야의 관점에서 더 전문적인 결과를 생성합니다.

**예제 10-4: 역할 지정의 효과**

역할을 지정하지 않은 프롬프트와 지정한 프롬프트의 차이를 살펴봅시다.

역할 없이 요청한 경우:

> "로그인 함수 만들어줘"

```python
# 역할 없는 프롬프트의 결과: 기본적인 로그인
def basic_login(username, password):
    """기본적인 로그인 — 보안 고려 없음"""
    if username == "admin" and password == "1234":
        return True
    return False
```

역할을 지정하여 요청한 경우:

> "당신은 10년 경력의 시니어 Python 보안 개발자입니다. 보안 모범 사례를 준수하는 로그인 검증 함수를 작성해주세요. 비밀번호 해싱, 입력 검증, 로그 기록을 포함해주세요."

```python

    input_hash = hashlib.sha256(password.encode()).hexdigest()
```

### 2) 맥락 (Context) - "이런 상황입니다"

프로젝트의 배경 정보를 제공하면 AI가 상황에 맞는 코드를 생성합니다.

**예제 10-5: 맥락 제공의 효과**

맥락 없이 요청한 경우:

> "설정 파일 읽는 함수 만들어줘"

```python
# 맥락 없는 결과: 단순한 파일 읽기
def read_config_no_context(filepath):
    """맥락 없는 결과: 단순한 파일 읽기"""
    with open(filepath) as f:
        return f.read()
```

맥락을 포함하여 요청한 경우:

> "우리 프로젝트는 Python 3.11 기반 웹 크롤러입니다. 설정은 JSON 형식이고 다음 항목을 포함합니다: urls(크롤링할 URL 목록, 필수, 1개 이상), interval(크롤링 간격, 선택, 기본값 60), output_dir(결과 저장 경로, 선택, 기본값 ./output). 설정 파일을 읽고 각 필드를 검증하는 함수를 작성해줘."

```python
# 맥락 있는 결과: 프로젝트에 맞는 전용 설정 로더
def load_crawler_config(filepath):
    """웹 크롤러 설정 파일을 읽고 검증합니다."""
    # 1. 파일 존재 확인
    if not os.path.exists(filepath):
        raise FileNotFoundError(f"설정 파일을 찾을 수 없습니다: {filepath}")

    # 2. JSON 파싱
    with open(filepath, encoding="utf-8") as f:
        config = json.load(f)

    # 3. 필수 필드 확인 (urls)
    if "urls" not in config:
        raise ValueError("필수 필드 'urls'가 누락되었습니다.")

    # 4. URL 형식 검증
    for i, url in enumerate(config["urls"]):
        if not url.startswith(("http://", "https://")):
            raise ValueError(f"urls[{i}] 값이 올바른 URL이 아닙니다: {url}")

    # 5. 선택 필드 기본값 적용
    config["interval"] = config.get("interval", 60)
    config["output_dir"] = config.get("output_dir", "./output")
    return config
```

### 3) 요청 (Request) - "이것을 해주세요"

무엇을 해야 하는지 명확하게 서술합니다. 이 부분은 프롬프트의 핵심입니다.

### 4) 형식 (Format) - "이런 형태로 주세요"

결과물의 출력 형식을 지정합니다.

**예제 10-6: 출력 형식 지정하기**

> "학생 성적 데이터를 다음 3가지 형식으로 출력하는 함수를 각각 만들어줘: 1) JSON 형식 2) 표(table) 형식 3) 마크다운 리스트 형식"

```python
# JSON 형식 출력
def output_as_json(students):
    """JSON 형식으로 출력합니다."""
    result = []
    for s in students:
        avg = round((s["math"] + s["english"] + s["science"]) / 3, 1)
        result.append({"이름": s["name"], "수학": s["math"],
                        "영어": s["english"], "과학": s["science"], "평균": avg})
    return json.dumps(result, ensure_ascii=False, indent=2)

# 표(table) 형식 출력
def output_as_table(students):
    """표(table) 형식으로 출력합니다."""
    header = f"{'이름':<10} {'수학':>6} {'영어':>6} {'과학':>6} {'평균':>6}"
    separator = "-" * len(header)
    lines = [header, separator]
    for s in students:
        avg = round((s["math"] + s["english"] + s["science"]) / 3, 1)
        lines.append(f"{s['name']:<10} {s['math']:>6} {s['english']:>6} "
                     f"{s['science']:>6} {avg:>6}")
    lines.append(separator)
    return "\n".join(lines)
```

### RCRF 구조 요약

네 가지 요소를 모두 포함한 프롬프트의 예시입니다:

```
[역할]   당신은 시니어 Python 백엔드 개발자입니다.
[맥락]   우리 프로젝트는 Flask 기반 REST API 서버이며,
         PostgreSQL 데이터베이스를 사용합니다.
[요청]   사용자 프로필을 조회하는 API 엔드포인트를 작성해주세요.
[형식]   코드에 타입 힌트와 docstring을 포함하고,
         에러 응답은 JSON 형식으로 반환해주세요.
```

모든 프롬프트에 네 가지 요소를 반드시 포함할 필요는 없습니다. 간단한 요청이라면 **요청**만으로 충분할 수 있습니다. 하지만 복잡한 작업일수록 RCRF 구조를 활용하면 결과의 품질이 크게 향상됩니다.

## 10.4 구체적으로 요청하기

프롬프트 엔지니어링에서 가장 기본적이면서도 가장 중요한 원칙은 **구체적으로 요청하기**입니다. 이 절에서는 세 가지 실전 비교 예제를 통해 구체적인 프롬프트의 위력을 확인합니다.

### 예제 10-1: 정렬 요청 - 나쁜 프롬프트 vs 좋은 프롬프트

나쁜 프롬프트:

> "정렬 해줘"

이 요청은 다음과 같은 정보가 빠져 있습니다:
- **무엇을** 정렬하나요? (숫자? 문자열? 객체?)
- **어떤 순서**로 정렬하나요? (오름차순? 내림차순?)
- **어떤 알고리즘**을 사용하나요? (내장 함수? 버블 정렬? 퀵 정렬?)
- **과정을 출력**하나요? (단순 결과만? 중간 과정도?)

좋은 프롬프트:

> "정수 리스트를 받아 내림차순으로 버블 정렬하고, 각 단계(pass)를 출력하는 함수를 작성해줘. 함수명은 bubble_sort_descending으로 해줘."

```python
def bubble_sort_descending(numbers):
    """내림차순 버블 정렬 — 각 단계를 출력합니다."""
    arr = numbers.copy()
    n = len(arr)
    print(f"원본 리스트: {arr}")
    print(f"목표: 내림차순 버블 정렬\n")

    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] < arr[j + 1]:       # 내림차순이므로 < 비교
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        print(f"  Pass {i + 1}: {arr}")
        if not swapped:
            print("  (더 이상 교환 없음 — 조기 종료)")
            break
    print(f"\n정렬 결과: {arr}")
    return arr
```

```python
    with open(filepath, encoding="utf-8") as f:
        for line_num, line in enumerate(f, 1):
            word_count = len(line.split())
            stats["lines"].append({

                "word_count": word_count,
                "preview": line.strip()[:40]
            })
            stats["total_words"] += word_count

    print(f"파일: {filepath}")

    for info in stats["lines"]:
        print(f"{info['line_number']:>8} | {info['word_count']:>7} | {info['preview']}")
    print("-" * 55)
    print(f"{'총 줄 수':>8} : {len(stats['lines'])}")
    print(f"{'총 단어 수':>8} : {stats['total_words']}")
```

## 10.5 예제와 함께 요청하기 (Few-shot)

**Few-shot** 기법은 프롬프트에 **입력-출력 예시**를 몇 개 포함하여 AI가 원하는 패턴을 정확히 파악하도록 하는 방법입니다. "말로 설명하기 어려운 것은 예시로 보여주자"는 접근입니다.

### Few-shot이란?

Few-shot 학습은 소수의 예시(few examples)만으로 AI가 규칙을 파악하도록 하는 기법입니다.

| 용어 | 의미 | 예시 개수 |
|------|------|----------|
| Zero-shot | 예시 없이 요청 | 0개 |
| One-shot | 예시 1개 포함 | 1개 |
| Few-shot | 예시 2~5개 포함 | 2~5개 |

### 예제 10-7: Few-shot 예시 제공하기

> "다음 변환 규칙에 따라 문자열을 변환하는 함수를 작성해줘.

```python
def convert_to_pascal_snake(text):
```

3. **분류 작업**: 데이터를 카테고리별로 나눌 때
4. **코드 스타일**: 특정 코딩 스타일을 적용할 때

## 10.6 단계별로 요청하기 (Chain of Thought)

**Chain of Thought(CoT)** 기법은 AI에게 문제를 **단계별로** 풀도록 요청하는 방법입니다. 복잡한 문제를 한 번에 해결하라고 하면 실수가 생기기 쉽지만, 단계를 나누어 하나씩 풀게 하면 정확도가 크게 높아집니다.

### Chain of Thought란?

사람이 복잡한 수학 문제를 풀 때 단계별로 풀이를 적듯, AI에게도 "단계별로 생각해서 풀어줘"라고 요청하는 것입니다.

```
일반 프롬프트:
  "가장 자주 등장하는 단어 TOP 5를 찾아줘"

Chain of Thought 프롬프트:
  "가장 자주 등장하는 단어 TOP 5를 찾아줘.
   다음 단계를 따라 구현해줘:
   1단계: 텍스트를 소문자로 변환
   2단계: 특수문자를 제거
   3단계: 단어별로 분리
   4단계: 불용어(stopwords) 제거
   5단계: 단어 빈도 계산
   6단계: 상위 5개 추출
   각 단계의 중간 결과를 출력해줘."
```

### 예제 10-8: 단계별 사고 요청하기

프롬프트:

> "주어진 텍스트에서 가장 자주 등장하는 단어 TOP 5를 찾아줘. 다음 단계를 따라 구현해줘: 1단계: 텍스트를 소문자로 변환 / 2단계: 특수문자를 제거 / 3단계: 단어별로 분리 / 4단계: 불용어 제거 / 5단계: 단어 빈도 계산 / 6단계: 상위 5개 추출. 각 단계의 중간 결과를 출력해줘."

```python
def find_top_words_step_by_step(text, top_n=5):
    """
    텍스트에서 가장 자주 등장하는 단어 TOP N을 단계별로 찾습니다.
    """
    print(f"[원본 텍스트]\n  {text[:80]}...\n")

    # 1단계: 소문자 변환
    step1 = text.lower()
    print(f"[1단계] 소문자 변환:")
    print(f"  {step1[:80]}...\n")

    # 2단계: 특수문자 제거
    step2 = re.sub(r'[^\w\s가-힣]', '', step1)
    print(f"[2단계] 특수문자 제거:")
    print(f"  {step2[:80]}...\n")

    # 3단계: 단어별로 분리
    step3 = step2.split()
    print(f"[3단계] 단어 분리 (총 {len(step3)}개):")
    print(f"  {step3[:10]} ...\n")

    # 4단계: 불용어 제거
    step4 = [w for w in step3 if w not in STOPWORDS_KO and len(w) > 1]
    print(f"[4단계] 불용어 제거 ({len(step3) - len(step4)}개 제거)\n")

    # 5단계: 빈도 계산
    step5 = Counter(step4)
    print(f"[5단계] 단어 빈도 계산:")
    for word, count in step5.most_common(8):
        bar = "#" * count
        print(f"  {word:<12} : {count:>3}회 {bar}")

    # 6단계: 상위 N개 추출
    step6 = step5.most_common(top_n)
    print(f"\n[6단계] 상위 {top_n}개 추출:")
    for rank, (word, count) in enumerate(step6, 1):
        print(f"  {rank}위: {word} ({count}회)")

    return step6
```

| 상황 | 단계 분해 예시 |
|------|-------------|
| 데이터 처리 | 읽기 --> 정제 --> 변환 --> 분석 --> 출력 |
| 알고리즘 구현 | 입력 검증 --> 핵심 로직 --> 결과 정리 --> 반환 |
| 에러 처리 | 에러 감지 --> 원인 분석 --> 복구 시도 --> 로그 기록 |
| 파일 작업 | 경로 확인 --> 파일 읽기 --> 내용 처리 --> 결과 저장 |

> **Tip:** Chain of Thought 프롬프트를 작성할 때는 "다음 단계를 따라 구현해줘"라는 문구와 함께 **번호가 매겨진 단계 목록**을 제공하세요. "각 단계의 중간 결과를 출력해줘"를 추가하면 디버깅에도 유용한 코드가 생성됩니다.

## 10.7 제약조건과 프롬프트 템플릿

### 제약조건 명시하기

프롬프트에 제약조건을 명시하면 AI가 조건에 맞는 코드를 생성합니다. 기술적 제한, 성능 요구사항, 사용 가능한 도구 등을 구체적으로 알려주세요.

**예제 10-9: 제약조건 명시하기**

프롬프트:

> "외부 라이브러리 없이 표준 라이브러리만 사용해서 간단한 HTTP 서버의 상태를 확인하는 헬스체크 함수를 작성해줘. 제약조건: 표준 라이브러리만 사용(requests 등 외부 패키지 금지), 타임아웃 3초, 결과는 딕셔너리로 반환, 상태코드/응답시간/서버 상태를 포함."

```python
# 표준 라이브러리만 사용!
import urllib.request
import urllib.error
import time
import ssl


def health_check(url, timeout=3):
    """
    HTTP 서버 헬스체크 — 표준 라이브러리만 사용.

    제약조건:
    - 외부 라이브러리 없음 (urllib만 사용)
    - 타임아웃 3초
    - 딕셔너리 반환
    """
    result = {
        "url": url,
        "status_code": None,
        "response_time_ms": None,
        "status": "unknown",
        "message": "",
    }

    start = time.time()
    try:
        req = urllib.request.Request(url, method="GET")
        req.add_header("User-Agent", "HealthCheck/1.0")
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            elapsed = (time.time() - start) * 1000
            result["status_code"] = resp.status
            result["response_time_ms"] = round(elapsed, 2)
            result["status"] = "healthy"
            result["message"] = "서버가 정상적으로 응답하고 있습니다."
    except urllib.error.HTTPError as e:
        result["status_code"] = e.code
        result["status"] = "error"
        result["message"] = f"HTTP 오류: {e.code} {e.reason}"
    except urllib.error.URLError as e:
        result["status"] = "unreachable"
        result["message"] = f"서버에 연결할 수 없습니다: {e.reason}"

    return result
```

### 프롬프트 템플릿 활용하기

자주 사용하는 프롬프트 패턴을 **템플릿**으로 만들어 두면 매번 처음부터 작성할 필요 없이 변수만 바꿔서 재사용할 수 있습니다.

**예제 10-10: 프롬프트 템플릿 활용**

```python
class PromptTemplate:
    """재사용 가능한 프롬프트 템플릿 클래스."""

    def __init__(self, name, template):
        self.name = name
        self.template = template

    def render(self, **kwargs):
        """템플릿에 값을 채워 넣어 완성된 프롬프트를 반환합니다."""
        return self.template.format(**kwargs)


# 함수 생성 템플릿
FUNCTION_TEMPLATE = PromptTemplate(
    name="함수 생성",
    template="""당신은 시니어 Python 개발자입니다.
다음 요구사항에 맞는 함수를 작성해주세요.

함수명: {function_name}
설명: {description}
매개변수: {parameters}
반환 타입: {return_type}
제약조건: {constraints}

코드에 타입 힌트와 docstring을 포함해주세요."""
)
```

이 템플릿을 사용하면 변수만 바꿔서 일관된 프롬프트를 생성할 수 있습니다:

```python
# 템플릿 사용 예시
prompt = FUNCTION_TEMPLATE.render(
    function_name="calculate_discount",
    description="상품 가격과 할인율을 받아 할인된 가격을 계산",
    parameters="price: float, discount_rate: float (0~100)",
    return_type="float (할인된 가격)",
    constraints="할인율은 0~100 사이, 음수 가격 불허",
)
```

## 정리

| 좋은 프롬프트의 5가지 특징 | 구체적, 맥락 포함, 예시 제공, 형식 지정, 제약조건 명시 | 5가지 체크 |

| Chain of Thought | 단계별로 분해하여 요청 | 단계별 사고 |
| 프롬프트 템플릿 | 재사용 가능한 프롬프트 패턴 | 템플릿화 |

### 실전 적용 가이드

프롬프트를 작성하기 전에 다음 순서로 생각해보세요:

1. **목표 확인**: 무엇을 만들고 싶은가?
2. **구체화**: 입력, 출력, 동작, 예외 처리를 명확히 한다
3. **맥락 추가**: 프로젝트 배경과 기술 환경을 알려준다
4. **형식 지정**: 원하는 출력 형태를 명시한다
5. **제약조건**: 기술적 제한이나 요구사항을 추가한다
6. **예시 포함**: 필요하면 입출력 예시를 제공한다
7. **단계 분해**: 복잡하면 단계별로 나누어 요청한다

> **Tip:** 처음부터 완벽한 프롬프트를 작성하려 하지 마세요. 간단한 프롬프트로 시작해서 결과를 보고, 부족한 부분을 추가하며 점진적으로 개선하는 것이 실전에서 가장 효과적인 방법입니다.
