# 함께해요 바이브 코딩

> AI와 함께하는 새로운 프로그래밍 여정

## 소개

"함께해요 바이브 코딩"은 AI와 함께 코딩하는 새로운 패러다임인 **바이브 코딩(Vibe Coding)**을 소개하는 한국어 전자책입니다.

### 바이브 코딩이란?

2024년 Andrej Karpathy가 소개한 개념으로, AI에게 자연어로 원하는 것을 설명하고, AI가 코드를 생성하며, 개발자는 결과를 확인하고 방향을 조정하는 프로그래밍 방식입니다.

> "There's a new kind of coding I call 'vibe coding', where you fully give in to the vibes, embrace exponentials, and forget that the code even exists."
> — Andrej Karpathy

## 책의 구성

| Part | 제목 | 내용 |
|------|------|------|
| Part 1 | 바이브 코딩 소개 | 바이브 코딩의 정의, 역사, AI 어시스턴트 |
| Part 2 | 시작하기 | 환경 설정, CLI 기초, 첫 경험 |
| Part 3 | 기초 | 프롬프트 작성, 대화 기술, 디버깅 |
| Part 4 | 실전 | 파일 처리, API, 웹 스크래핑 |
| Part 5 | 심화 | 프로젝트 관리, 테스트, 보안 |
| Part 6 | 프로젝트 | CLI 앱, 블로그 생성기, 대시보드 |
| 부록 | 참고 자료 | 도구 비교, 템플릿, 용어집 |

## 대상 독자

- 프로그래밍을 처음 시작하는 분
- AI 코딩 도구에 관심 있는 개발자
- 생산성을 높이고 싶은 개발자
- PM, 디자이너 등 비개발 직군

## 프로젝트 구조

```
JoinUsForVibeCoding/
├── book/                # 전자책 본문 (마크다운)
├── examples/            # 예제 코드
│   ├── python/
│   ├── javascript/
│   └── bash/
├── assets/              # 이미지, 다이어그램
├── scripts/             # 빌드 스크립트

├── CLAUDE.md            # Claude Code 가이드
├── PRD.md               # 제품 요구사항
├── TRD.md               # 기술 요구사항
├── TODO.md              # 작업 목록

```

## 예제 실행
